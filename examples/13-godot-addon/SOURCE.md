# Source of truth: PartiiGames/partii-godot

This folder is a copy of https://github.com/PartiiGames/partii-godot at commit `502d5d9`
(first made from the Smashii port's export, 2026-11-23). Fixes and releases happen there, and it is
what Godot's Asset Library installs. Don't edit this copy: change partii-godot, then copy it here again
and update the commit above.

Installing in your game: Godot's AssetLib tab (search "Partii"), or copy `addons/partii/` from
partii-godot. Stamp nothing: the add-on is Partii's code, so you install it whole, like a package,
and update it from partii-godot.
